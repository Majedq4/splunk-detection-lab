# T1059.001 — PowerShell Execution

**Date:** April 25, 2026
**Tool:** Atomic Red Team
**Command:** `Invoke-AtomicTest T1059.001`
**Defender Status:** Disabled during test

---

## Hypothesis
Threat actor executes scripts and commands using `powershell.exe` 
directly in memory (fileless) or from disk to evade detection.

Expected event sources:
- PowerShell log — EventCode 4104, 4103, 4100
- Security log — EventCode 4688 (Process Creation)
- Sysmon — EventCode 1 (Parent-Child), 3 (Network), 7 (DLL Loading)

---

## Attack Overview
Threat actor uses PowerShell to download files, modify configurations, 
and interact with the .NET framework — all without writing to disk.

Suspicious cmdlets to hunt for:
- `iex`, `iwr`, `Invoke-WebRequest`, `DownloadString`
- `-ExecutionPolicy Bypass`, `-NoProfile`, `-NonInteractive`
- `-WindowStyle Hidden`, `-enc` (encoded commands)

---

## Hunt Queries

**1. Script Block Logging — keyword search**
```splunk
index=main sourcetype="WinEventLog:PowerShell" EventCode=4104
(*iex* OR *iwr* OR *Invoke-WebRequest* OR *bypass* OR *DownloadString* OR *hidden*)
```

**2. Module Logging — find executed commands**
```splunk
index=main sourcetype="WinEventLog:PowerShell" EventCode=4103
```

**3. Parent-Child process analysis**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=1
(CommandLine="*mimikatz*" OR CommandLine="*sekurlsa*" OR CommandLine="*lsadump*")
```

**4. Network connections during attack window**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=3
| table _time, Image, DestinationIp, DestinationPort
```

## Verdict
**Malicious** — Attacker used PowerShell to download post-exploitation 
scripts directly into memory from GitHub CDN.

- Affected user: `DESKTOP-TPK5FB3\demo`
- Tools downloaded: Mimikatz, PowerUp, Invoke-AppPathBypass

---

## ATT&CK Mapping
- Tactic: Execution
- Technique: T1059.001 — PowerShell
- Sub-behavior: Fileless script download via `iex`/`iwr`

## Detection Rule
```splunk
index=main sourcetype="WinEventLog:PowerShell" EventCode=4104
(*iex* OR *iwr* OR *Invoke-WebRequest* OR *bypass* OR *DownloadString* OR *hidden*)
```

---

## Lessons Learned
- Patience is critical — 1000+ events requires smart filtering 
  via `| head 20` and `| rare`, not manual browsing
- Always complete the hypothesis — all listed event sources must be queried
