# T1547.001 — Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder

**Date:** April 27, 2026
**Tool:** Atomic Red Team
**Command:** `Invoke-AtomicTest T1547.001`
**Defender Status:** Disabled during test

---

## Hypothesis
Attacker creates persistence via registry run keys or startup folders,
which can be identified in Sysmon EventCode 12 and 13 for registry 
modification, and EventCode 11 for file creation.

---

## Attack Overview
Attackers achieve persistence by adding a program to a startup folder 
or referencing it with a registry run key. The machine executes the 
malicious file automatically on next login or boot.

Common paths abused:
- `C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp`
- `[Username]\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`
- `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`
- `HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnce`
- `HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnceEx`
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders`
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders`

Common commands used by attackers:
`reg add`, `New-ItemProperty`, `Copy-Item`

---

## Hunt Queries

**1. Registry run key modifications**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=13
*CurrentVersion*
| stats count by TargetObject
| sort count asc
```

**2. Files dropped in startup folders**
```splunk
index=main *Roaming*
| stats count by TargetFilename
| sort count asc
```

**3. Registry key creation (EventCode 12)**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=12
TargetObject IN ("*\\CurrentVersion\\Run*", "*\\CurrentVersion\\RunOnce*")
| table _time, EventType, TargetObject, Image, User
```

**4. Startup folder file creation (EventCode 11)**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=11
TargetFilename="*\\Startup\\*"
| table _time, Image, TargetFilename, User
```

## Verdict
**Malicious** — Multiple persistence mechanisms established simultaneously:
- Registry run keys written across HKLM and HKU hives
- Winlogon hijacked via Userinit modification
- Multiple file types dropped in startup folder
- SOCKS5 PowerShell C2 tunnel configured via run key
- Affected user: `DESKTOP-TPK5FB3\demo`

## Detection Rules

**Registry persistence:**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=13
TargetObject IN ("*\\CurrentVersion\\Run\\*", "*\\CurrentVersion\\RunOnce\\*", 
"*\\CurrentVersion\\RunOnceEx\\*", "*\\Winlogon\\*")
| table _time, TargetObject, Details, Image, User
```

**Startup folder file drop:**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=11
TargetFilename="*\\Startup\\*"
| table _time, Image, TargetFilename, User
```

---

## Lessons Learned
- EventCode 15 is extremely useful — provides file hash and 
  content of created files, enabling immediate malware identification
- `services.exe` writing to Run keys is an absolute red flag — 
  legitimate services never do this
- RunOnceEx is hidden from Autoruns.exe by default — 
  always check this key manually during incident response
- SOCKS5 run key indicates C2 infrastructure — escalate immediately
  in a real environment
