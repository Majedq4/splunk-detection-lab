# T1059.003 — Windows Command Shell

**Date:** April 26, 2026
**Tool:** Atomic Red Team
**Command:** `Invoke-AtomicTest T1059.003`
**Defender Status:** Disabled during test

---

## Hypothesis
Threat actor uses `cmd.exe` to execute commands and scripts. 
Suspicious cmd.exe activity will appear in Sysmon EventCode 1, 
particularly when spawned from unusual parent processes.

---

## Attack Overview
Threat actor invokes Windows Command Shell to run commands locally 
or remotely via SSH. Common indicators include:
- `cmd.exe` spawned from `powershell.exe`, `wscript.exe`, or `mshta.exe`
- Commands written to or executed from TEMP directory
- Reconnaissance commands like `whoami`

---

## Hunt Queries

**1. Identify all cmd.exe executions**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=1
| stats count by Image
| sort count asc
```

**2. Find suspicious parent processes spawning cmd.exe**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=1
Image="C:\\Windows\\System32\\cmd.exe"
ParentImage IN ("*powershell*", "*wscript*", "*mshta*", "*rundll32*")
| table _time, ParentImage, Image, CommandLine, User, host
```

**3. Find files dropped in TEMP directory**
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=11
TargetFilename="*\\Temp\\*"
| table _time, Image, TargetFilename, User
```

## Detection Rule
```splunk
index=main sourcetype="WinEventLog:Sysmon" EventCode=1
Image="C:\\Windows\\System32\\cmd.exe"
(ParentImage="*powershell*" OR ParentImage="*wscript*" 
OR CommandLine="*whoami*" OR CommandLine="*TEMP*")
| table _time, ParentImage, Image, CommandLine, User, host
| sort - _time
```
